## 五、关键技术实现

### 5.1 useEffect 的作用

本实验中 useEffect 主要完成两个任务：

```jsx
// 页面初始渲染后处理输入框聚焦
useEffect(() => {
  if (inputRef.current) {
    inputRef.current.focus();
  }
}, []);

// 当课程列表变化时，同步保存到 localStorage（在 useLocalStorage 中实现）
useEffect(() => {
  window.localStorage.setItem(key, JSON.stringify(storedValue));
}, [key, storedValue]);
```

这体现了 useEffect 处理副作用的作用。副作用包括数据请求、定时器、订阅、DOM 操作等，本实验中的本地存储与输入框聚焦都属于副作用处理。

### 5.2 useRef 的作用

```jsx
const inputRef = useRef(null);

// 在 JSX 中绑定引用
<input ref={inputRef} type="text" placeholder="请输入课程名称 *" />

// 在需要时调用 focus()
inputRef.current.focus();
```

useRef 用于获取输入框 DOM 引用，并在新增课程或页面初始化时自动聚焦。它不会触发重新渲染，适合保存 DOM 节点或可变值。

### 5.3 useMemo 的作用

```jsx
const filteredCourses = useMemo(() => {
  console.log('🔍 执行课程筛选计算...');
  return courses.filter(course => {
    const matchSearch = course.title.toLowerCase().includes(debouncedSearchTerm.toLowerCase());
    const matchCategory = categoryFilter === '全部' || course.category === categoryFilter;
    return matchSearch && matchCategory;
  });
}, [courses, debouncedSearchTerm, categoryFilter]);
```

课程搜索时，需要根据关键词对课程列表进行过滤。若每次渲染都重新计算，可能造成性能浪费，因此使用 useMemo 对筛选结果进行缓存，仅在课程列表或搜索关键词变化时重新计算。

### 5.4 useCallback 的作用

```jsx
const handleDeleteCourse = useCallback((id) => {
  setCourses(prev => prev.filter(course => course.id !== id));
  showToast('课程已删除', 'success');
}, [setCourses, showToast]);
```

handleLearn、handleAddCourse、handleDeleteCourse 作为函数传入子组件，如果每次渲染都重新创建，可能会引发不必要的子组件更新。因此使用 useCallback 缓存函数引用，使组件结构更清晰。

### 5.5 自定义 Hook 的作用

#### useLocalStorage

```jsx
export function useLocalStorage(key, initialValue) {
  const [storedValue, setStoredValue] = useState(() => {
    const item = window.localStorage.getItem(key);
    return item ? JSON.parse(item) : initialValue;
  });

  useEffect(() => {
    window.localStorage.setItem(key, JSON.stringify(storedValue));
  }, [key, storedValue]);

  return [storedValue, setStoredValue];
}
```

封装本地存储逻辑，实现：
- 懒初始化读取 localStorage
- 自动同步写入 localStorage
- 支持多标签页数据同步

#### useDebounce

```jsx
export function useDebounce(value, delay = 300) {
  const [debouncedValue, setDebouncedValue] = useState(value);

  useEffect(() => {
    const timer = setTimeout(() => {
      setDebouncedValue(value);
    }, delay);

    return () => clearTimeout(timer);
  }, [value, delay]);

  return debouncedValue;
}
```

实现搜索防抖，避免每输入一个字符就立刻触发搜索逻辑，提升性能。

## 九、实验总结

通过本次实验，我深入理解了 React Hooks 的核心概念和实际应用场景：

1. **useState** 是状态管理的基础，配合其他 Hooks 使用
